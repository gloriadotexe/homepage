## Running Locally

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your API keys for Tumblr, Pollinations, etc.

# Start development server
npm run dev

# Run tests
npm test

# Format code
npm run format
```

Runs on `http://localhost:3001`
